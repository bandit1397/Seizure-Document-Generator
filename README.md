# 압수서류 자동작성기

압수조서와 압수목록만 직접 입력하면 **압수목록 교부서 · 임의제출 · 소유권 포기서**가 자동으로 채워지는 프로그램입니다.

- 설치 없음: `index.html` 파일 하나로 동작합니다(인터넷 연결 불필요, 외부 서버로 전송 없음).
- 실행: `압수서류 자동작성기 실행.bat` 더블클릭(또는 `index.html`을 브라우저로 열기).

## 사용 순서

1. **① 압수조서 입력** — 관서, 죄명, 피의자, 압수일시·장소, 압수 근거, 압수자·참여 경찰관, 압수 경위, 참여인
2. **② 압수목록 입력** — 압수물별 품종·수량·특징, 소지자(제출자)와 소유자의 성명·주민번호·직업·주소·전화번호, 제출자의 처분의견
3. 오른쪽 탭에서 5개 서류를 확인 → **`HWP 저장`**(공식 서식원본 HWP에 값을 채운 .hwp 파일) 또는 `인쇄`
4. `사건 저장(.json)`으로 사건을 저장해 두고, 나중에 `사건 열기`로 불러옵니다.

## 서식 근거 (국가법령정보센터 현행 서식)

| 서류 | 근거 서식 | 데이터 출처 | 작성 조건 |
|---|---|---|---|
| 압수조서 | 경찰수사규칙 별지 제66호서식 | 압수조서 입력 | 항상 |
| 압수목록 | 경찰수사규칙 별지 제67호서식 | 압수목록 입력 | 항상 (1쪽 6건, 초과 시 다음 쪽) |
| 압수목록 교부서 | 경찰수사규칙 별지 제68호서식 | 압수조서 + 압수목록 소지자 | 항상 — 피압수자 1인당 1장 |
| 임의제출 | 범죄수사규칙 별지 제62호서식 | 압수목록 제출자·처분의견 | 압수 근거가 '임의제출'일 때만 |
| 소유권 포기서 | 범죄수사규칙 별지 제60호서식 | 압수목록 소유자 + 압수조서 사건정보 | '소유권 포기' 체크된 압수물이 있을 때만 |

`서식원본/` 폴더에 국가법령정보센터에서 받은 원본 HWP·PDF가 있습니다(경찰수사규칙 2026. 10. 2. 시행, 범죄수사규칙 경찰청훈령 제1232호 기준).

임의제출 의사, 소유권 포기 의사, 압수목록 수령 사실은 프로그램이 대신 확정하지 않습니다. 서명란은 비워 두고, 절도·장물 등 피해품을 소지자 소유로 보고 포기서를 만들려 하면 경고를 띄웁니다.

## HWP 저장 방식

`HWP 저장`은 `서식원본/`의 공식 HWP 파일을 그대로 열어 표 칸에 값만 채운 뒤 .hwp로 내려받습니다. 한글 프로그램이나 다른 설치 없이 브라우저(Chrome·Edge 최신 버전)만으로 동작합니다.

- 서식의 글꼴·표·칸 배치는 원본 그대로이고, 채운 칸의 줄 나눔은 한글이 파일을 열 때 다시 계산합니다.
- 원본의 누름틀(○○○, 계급, 작성자 등)은 입력값으로 바뀝니다. 입력하지 않은 칸은 원본 그대로 남습니다.
- 압수목록 6건, 교부서 17건, 임의제출 8건, 포기서 9건을 넘으면 `_2`, `_3` 파일로 이어서 만들어집니다. 교부서·임의제출·포기서는 사람별로 따로 만들어집니다.
- 여러 파일을 한 번에 받을 때 브라우저가 "여러 파일 다운로드 허용"을 물으면 허용하세요.

| 파일 | 역할 |
|---|---|
| `hwp-fill.js` | HWP(복합 파일·레코드) 읽기/쓰기, 문단 글자 바꾸기 |
| `hwp-forms.js` | 서식별로 어느 칸에 어떤 값을 넣을지 |
| `hwp-templates.js` | 서식원본 HWP를 담은 파일 (`node tools/build-templates.js`로 생성) |
| `case.js` | 날짜·조사·인원 묶기 등 화면과 HWP가 함께 쓰는 문구 함수 |
| `compat.js` | 구형 브라우저(IE11 등)에 없는 기능만 채우는 보완 코드 (최신 브라우저에서는 아무 일도 안 함) |
| `pako.es5.min.js` | 브라우저에 압축 기능이 없을 때 HWP 압축에 쓰는 라이브러리 (pako 2.1.0, MIT·Zlib 라이선스) |
| `tools/test-fill.js` | 개발용: 예시 사건으로 HWP를 만들어 보는 스크립트 |

서식이 개정되면 새 원본을 `서식원본/`에 넣고 `node tools/build-templates.js`를 실행한 뒤, `HwpFill.inspect()`로 칸 주소를 확인해 `hwp-forms.js`를 고칩니다.

## 구형 브라우저(인터넷 익스플로러 11) 지원

내부망 PC처럼 기본 브라우저가 IE11이거나 Chrome·Edge가 오래된 경우에도 같은 기능이 동작합니다.

- 최신 Chrome·Edge에서는 기존과 똑같이 동작합니다. 보완 코드와 IE 전용 화면 규칙은 해당 기능이 없는 브라우저에서만 적용됩니다.
- IE에는 날짜 선택 칸이 없어서 압수일시는 `2026-10-12 12:00`, 작성일은 `2026-10-12` 형식으로 직접 입력합니다.
- IE에서는 바탕화면에서 연 페이지의 자동 저장(localStorage)이 되지 않을 수 있습니다. `사건 저장(.json)`으로 보관하세요.
- IE에서 HWP를 저장하면 화면 아래 저장 알림줄이 뜹니다. 여러 파일을 한 번에 받을 때 일부가 빠지면 `이 서류 HWP 저장`으로 하나씩 받으세요.

## 참고

- 화면 미리보기·인쇄는 원본 서식을 HTML로 재현한 것이고, HWP 저장은 원본 파일 자체를 씁니다.
- 입력 내용은 브라우저에 자동 저장됩니다(같은 PC·같은 브라우저 한정). 확실히 보관하려면 `사건 저장(.json)`을 쓰세요.
