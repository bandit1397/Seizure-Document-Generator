# 압수서류 자동작성기

압수조서와 압수목록만 직접 입력하면 **압수목록 교부서 · 임의제출서 · 소유권포기서**가 자동으로 채워지는 프로그램입니다.

- 설치 없음: `index.html` 파일 하나로 동작합니다(인터넷 연결 불필요, 외부 서버로 전송 없음).
- 실행: `압수서류 자동작성기 실행.bat` 더블클릭(또는 `index.html`을 브라우저로 열기).

## 사용 순서

1. **① 압수조서 입력** — 관서, 죄명, 피의자, 압수일시·장소, 압수 근거, 압수자·참여자, 압수 경위
2. **② 압수목록 입력** — 압수물별 품종·수량·특징, 소지자(제출자)와 소유자의 성명·주민번호·주소·연락처
3. 오른쪽 탭에서 5개 서류를 확인 → `인쇄` 또는 `.doc 저장`(아래한글에서 열어 편집 가능)
4. `사건 저장(.json)`으로 사건을 저장해 두고, 나중에 `사건 열기`로 불러옵니다.

## 자동 작성 규칙

| 서류 | 데이터 출처 | 작성 조건 |
|---|---|---|
| 압수조서 (별지 제66호) | 압수조서 입력 | 항상 |
| 압수목록 (별지 제67호) | 압수목록 입력 + 압수조서 일시·장소·압수자 | 항상 |
| 압수목록 교부서 (별지 제68호) | 압수목록의 소지자(피압수자)별 | 항상 — 피압수자가 여럿이면 1인당 1장 |
| 임의제출서 | 압수목록의 제출자별 | 압수 근거가 '임의제출'일 때만 |
| 소유권포기서 | 압수목록의 소유자별 | 압수물에 '소유권 포기' 체크가 있을 때만 |

임의제출 의사, 소유권 포기 의사, 압수목록 수령 사실은 프로그램이 대신 확정하지 않습니다. 서명란은 비워 두고, 절도·장물 등 피해품을 소지자 소유로 보고 포기서를 만들려 하면 경고를 띄웁니다.

## 참고

- 서식 배치는 경찰수사규칙 별지 서식을 참고해 HTML로 재현한 것입니다. 실제 사용 중인 HWP 원본과 문구·칸 배치가 다르면 맞춰 수정해야 합니다.
- 입력 내용은 브라우저에 자동 저장됩니다(같은 PC·같은 브라우저 한정). 확실히 보관하려면 `사건 저장(.json)`을 쓰세요.
